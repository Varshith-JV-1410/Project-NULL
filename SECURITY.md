# Security Policy

## Responsible Use

This research is provided for:

- ✅ Authorized penetration testing
- ✅ Security research in isolated environments
- ✅ Educational purposes
- ✅ Defensive tool development (testing detection rules)

This tool is NOT provided for:

- ❌ Unauthorized access to systems
- ❌ Malicious attacks
- ❌ Any illegal activity

## Reporting a Vulnerability

If you find a security issue in this repository (e.g., a bug in the build scripts that produces unsafe output, or an unintentional vulnerability in the code), please report it responsibly:

- **Preferred:** Open a [private security advisory](https://github.com/Varshith-JV-1410/Project-NULL/security/advisories/new) on GitHub.
- Alternatively, open a regular [GitHub issue](https://github.com/Varshith-JV-1410/Project-NULL/issues) if the issue is not sensitive.

Please do not disclose the issue publicly before it has been addressed. Expect an initial response within 7 days.
